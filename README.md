# Machine Learning e-Portfolio — GitHub Pages

This static website contains the course portfolio and 24 supporting images.

## Publishing
1. Create a public GitHub repository, e.g. `machine-learning-eportfolio`.
2. Upload `index.html`, `README.md`, and the entire `images/` folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, **main**, **/(root)**, then **Save**.
4. Visit `https://YOUR-USERNAME.github.io/machine-learning-eportfolio/` after deployment.

**Important:** GitHub file names are case-sensitive; keep image filenames unchanged, including spaces, the en dash in `Population–GDP Regression.png`, and the space in `Wiki .jpeg`.

Before submission, verify your reflection against the 1,000-word limit and the assignment requirements, add any required links to original notebooks/artefacts, and check whether private peer evaluation information is suitable for a public repository.
